# План: авто-кулдаун тем (домен-пауза по времени)

> Задача на след. сессию (шлифовка). Поставлена 02.07.2026 после того, как флагман заработал (tag
> `flagship-good-v1`). НЕ срочно, ничего не ломает — улучшение, чтобы убрать ручной костыль.

## Проблема
`PAUSED_DOMAINS` в `core/dedup.py` — **ручной ПОСТОЯННЫЙ список**. Сейчас x402/стейблы/«смена рук»
заблокированы НАВСЕГДА, пока руками не удалить. Но это **не плохие темы** — просто передоз (3-4 поста
за ~2 недели). Хорошая тема должна ВЕРНУТЬСЯ, когда остынет, а не быть в вечном бане.

## Цель
Домен на паузе **ТОЛЬКО пока** по нему ≥2 поста за последние ~3 недели. Затих → **сам освобождается**.
Ручной список больше не ведём.

## Как сделать (всё в `core/dedup.py`, подачу/мануал НЕ трогать)
1. **Словарь доменов** (единственное, что ведём руками, меняется редко): домен → ключевые слова.
   Напр.: `стейблкоины`: x402/usdc/usdt/стейбл/cloudflare-платежи; `смена-рук`: смена рук/ETF-отток/
   скупка на дне; `майнеры`; `ставка-ФРС`; `MiCA`.
2. **`hot_domains()`**: берём посты за последние `COOLDOWN_DAYS` из данных канала (`post_topics.json` /
   выгрузка), матчим заголовок/суть по ключам, считаем. Домен с `≥ MIN_POSTS` → «горячий = на паузе».
3. **`recommended_theme` / `repeat_themes` используют `hot_domains()` вместо статического `PAUSED_DOMAINS`**:
   тема с ключом горячего домена → не рекомендуется + идёт в запрет Криейтору (как сейчас, но по факту дат).
4. **Удалить статический `PAUSED_DOMAINS`** (или оставить крошечный ручной override на форс-мажор).

## Крутилки
`COOLDOWN_DAYS = 21`, `MIN_POSTS = 2`. Подстроить на практике.

## Приёмка

- Через ~3-4 недели тишины по домену → **сам разблокировался**, писать снова можно.
- Руками список не ведём.

остыла — **просто удали нужные слова из `PAUSED_DOMAINS` вручную**, и домен снова доступен.
