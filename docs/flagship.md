# 💸 Флагман — образовательный длинный пост (ветка флагмана)

Документация **ветки флагмана** для инженера: что это, как выбирается тема, как строится подача,
как течёт прогон, как запускать и тюнить, что НЕ трогать.
Карта проекта — [ARCHITECTURE.md](ARCHITECTURE.md). Короткий формат 🔭 — [scope.md](scope.md).
**Правила самой рубрики** (структура, типографика, красные линии) — в
[../memory/content_manual.md](../memory/content_manual.md) (это «библия», аналог `scope_manual.md`).

> Состояние на 07.07.2026 (после перестройки). Реперная точка — git-тег `flagship-good-v2`.
> Эталонный пост: «💸 700 млрд$ домой каждый год. Банк или крипта?» — владелец: «не редактировал бы».

---

## 1. МОДЕЛЬ А — что это и главный принцип

Флагман = **ПОЛЬЗА + АКТУАЛЬНОСТЬ**:
- **ПОЛЬЗА** — тема ВСЕГДА из банка вечных тем (`memory/flagship_topics.md`), бренд-ядро
  (принятие/применение, AI×крипта, психология, механика, макро-оптика). НЕ из новостей.
- **АКТУАЛЬНОСТЬ** — Криейтор якорит вечную тему свежим (живая цифра через `market_price`, реальный
  пример/история), а выбор темы учитывает настроение рынка + свежий бриф.

**Новость как ТЕМА — это scope, не флагман.** Поэтому флагман **не гоняет Скаута** (разведку) — экономит
~$1.2/прогон. Единый вопрос каждого поста (канон brand.md): «мой тезис жив и крепнет — или где трещина?»

Ключевой урок перестройки: **примеры > растущий рулбук** (голос — с эталонов, не с запретника),
**бренд-фит темы** (не трейдер-механика), **вычитание, не добавление** (перегруженный гайд = деревянно).

## 3. Как выбирается ТЕМА (банк + пикер + актуальность + рециклинг)

1. **Банк** (`memory/flagship_topics.md`) — ~200 тем строками `- тема — угол`, 6 слоёв. Курирует владелец.
2. **Пикер по актуальности** (`run_pipeline._pick_timely_theme`): случайная выборка ~25 из ДОСТУПНЫХ
   (`dedup.available_bank_themes`) → один дешёвый вызов (Sonnet, ~$0.03) выбирает самую резонансную по:
   - **настроение рынка** (обязательно, `market_price` 24ч/7д): обвал/страх → психология удержания;
     ATH/жадность → поздний вход/FOMO; спокойно → принятие/AI или словарь;
   - **тематика свежего брифа** (бонус, `verify.latest_brief` — переиспользуем бриф scope-прогонов):
     горячий домен → тема из него точнее.
   Фолбэк — случайная (`dedup.pick_bank_theme`), если рынок/бриф/модель недоступны.
3. **Рециклинг** (`dedup.mark_theme_used`): при РЕАЛЬНОЙ публикации (не draft/test) тема метится в файле
   `- [вышло ГГГГ-ММ-ДД] …`. Пикер не берёт её `BANK_REUSE_DAYS`=180 дней, потом сама возвращается.
   Дефицита нет: при 200 темах и 1 флагмане/нед — ~4 года, и колесо крутится само.
   > Строка `[вышло]` без ISO-даты в ротацию НЕ идёт (защита от повторной выдачи).

## 4. Как строится ПОДАЧА (голос)

- **Эталоны** (`_anchors` в creator_bot): полный текст 3–4 постов-образцов (`ANCHOR_FALLBACK`
  `[381, 422, 417, 445]` или `memory/anchor_posts.md`) вшит в контекст — «пиши В ЭТОМ голосе».
  Голос переносится с ПРИМЕРОВ, не с растущего запретника.
- **Гайд вечного слота** (в `_run_creator`) — УЖАТ, позитивный: раскрой ИМЕННО выбранную тему + якорь на
  конкретике + **цель «тест гема»** (пост, которым делятся с другом: кругозор + человеческая/культурная
  деталь + бытовое сравнение больших денег + яркая метрика). Не своди к морали про DCA.
- **content_manual** §5 (типографика), §7 (запретник AI-паттернов) + **линтер** (`creator_tools`) —
  детерминированный enforce.
- **Дубль-проверка** (проход-чистка §6 в `COMMANDS["post"]`): смысловой дубль между блоками — один
  факт/тезис/ОБРАЗ в ОДНОМ месте (напр. «привязан к $ 1:1» + «держит цену 1:1» = повтор).

## 5. Как течёт прогон (флагман)

```
[0] Актуальность данных канала (dedup.refresh_if_stale) — общая сантехника
    Скаут для флагмана НЕ гоняется (Модель А)
[1] ТЕМА: _pick_timely_theme → одна тема из банка по актуальности (рынок+бриф)
[2] Криейтор (_run_creator, Opus): раскрывает тему по эталонам + якорь → save_draft (линтер)
    2FA-фактчек (verify, Sonnet) → Криейтор сам правит → перепроверка
    Обложка: make_image (GPT) — если не --no-image/тест
[3] Публикация в отложку канала → mark_theme_used (тема → [вышло сегодня])
```

## 6. Как запускать

```
python run_pipeline.py                # флагман: тема из банка по актуальности + якорь → отложка
python run_pipeline.py --draft-only   # драфт без публикации (тест) — тему НЕ метит [вышло]
python run_pipeline.py --no-image     # без GPT-обложки (только текст); в /test включается САМ
```
`/main` (бот) — боевой Opus; `/test` — дёшево на Haiku (качество подачи в тесте НЕ судить — Haiku).
Дешёвый честный тест качества: `/main` + `python run_pipeline.py --draft-only --no-image`.

**Сам по расписанию** (Вт/Чт, старт за 4ч до выхода) — автопилот: `python run_autopilot.py`
(`--status` — вердикт без запуска, `--daemon` — живым процессом). Решение «пора или нет» —
`core/schedule.py`, дни и время берёт из `content_plan` (вторая копия расписания не заводится).
Выключатель — файл `data/autopilot_on`, по умолчанию ВЫКЛЮЧЕНО. Настройка, предохранители и
чек-лист владельца — [AUTOPILOT.md](AUTOPILOT.md). Письма/промптов/банка автопилот не касается.

## 7. Отделено от scope

**Раздельно (не пересекается):** письмо, промпты, мануалы, банк, эталоны, уроки, 2FA, обложка.
Флагман = `_run_creator`/`content_manual`/эталоны; scope = `_run_scope`/`scope_writer`/`scope_manual`/
`voice_core` (см. [scope.md](scope.md)). Scope живёт как ДО перестройки — его не трогали.

**Общее (нейтральная сантехника):** выгрузка данных канала, Скаут-инструмент (Скаут крутится на scope,
его бриф переиспользует пикер флагмана), публикация. Голосу тут протекать нечему.

## 8. Тюнинг и что НЕ трогать

**Тюним свободно:**
- Банк тем — `memory/flagship_topics.md` (владелец/Аналитик). Строка `- тема — угол`; `[вышло ГГГГ-ММ-ДД]` метит пайплайн сам.
- Эталоны — `ANCHOR_FALLBACK` в `creator_bot.py` или `memory/anchor_posts.md`.
- Окно рециклинга — `dedup.BANK_REUSE_DAYS` (180). Размер выборки пикера — 25 в `_pick_timely_theme`.

**НЕ ломать (выстрадано):**
- Гайд вечного слота ужат НАМЕРЕННО — не раздувать запретами (перегруз = деревянно).
- Голос держат ЭТАЛОНЫ, не рулбук. Новые правила — в память как урок, не в гайд.
- Флагман Скаута для ТЕМЫ не гоняет (Модель А). Новость как тема = scope.
- Не сливать scope и флагман (правка одного не должна задевать другой).

**Открыто (backlog):** «садовник банка» — Аналитик раз в месяц предлагает новые темы + флагает старые
(propose→apply, владелец одобряет). Не срочно (запас ~4 года).
