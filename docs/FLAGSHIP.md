## TL;DR — закон флагмана (монолит)

> **ФЛАГМАН = ВЕЧНАЯ ТЕМА × СЕГОДНЯШНЕЕ НАСТРОЕНИЕ РЫНКА × ПЛОТНАЯ ПОДАЧА (одно сообщение).**

Три слоя, всегда все три. Убери любой — падаешь в один из трёх исторических провалов канала.

## Три слоя закона

1. **ХРЕБЕТ — вечная ТЕМА** (как работает / метод / психология / польза) из банка `flagship_topics.md`.
   Тест: **«убери новость — что останется?»** Останется польза через год → флагман. Нет → это 🔭 короткая
   заметка, не флагман. → Убери слой → **новостник** (провал 3). Это ядро идентичности канала.
2. **НАСТРОЕНИЕ — сегодняшний РЫНОК** (страх/жадность, тренд, 1–2 живые цифры) задаёт ТОН и КРЮЧОК.
   **Не ври настроению:** на страхе/обвале не пиши «всё отлично»; в эйфории не строй осторожного. Тон =
   что читатель реально чувствует сегодня. → Убери слой → пост вне времени, «опять база», **повтор** (провал 1).
3. **ПОДАЧА — плотно, одно сообщение ≤4096**, хук-сцена, простой язык, личный угол, «как это касается
   ЛИЧНО тебя». Глубина ≠ длина; глубина ≠ Notion. → Убери слой → **академ-статья, не читают** (провал 2).

## Почему «и тема, и свежесть» больше не спорят

Тема (хребет) — вечная, повторяется годами. Настроение рынка — всегда новое. **Одна тема × разное
настроение × свежий угол = дубля не бывает.** Свежесть идёт из НАСТРОЕНИЯ и УГЛА, а не из погони за
новостями. Тема не «одноразовая»: портфель/DCA/смена рук заходили по нескольку раз (#417/#422/#434 —
одна жила); повтор ловится на уровне ПРИЁМА (content_manual §4.5), а не запретом возвращаться к теме.

## Откуда берутся темы (колодец не пересыхает)

Дефицит тем — то, что и толкнуло в новостник. Закрыто двумя вещами:

- **Банк `memory/flagship_topics.md`** — 52 темы из записника владельца, по 6 категориям (психология /
  метод / сравнения / оптика-макро / технология / безопасность). Помечено `≈#id`, где похожее выходило
  (освежать углом, не дублировать). Трамп = политота (⛔), рефки = служебное (не флагман).
- **5 генераторов** (каждый рождает десятки не-дублирующих тем): (1) механика «как это работает» ×
  объект; (2) миф → разбор; (3) личный урок × своя ошибка/решение; (4) сравнение × две вещи;
  (5) ментальная модель × перенос в жизнь. Свежесть — из нового угла через генератор.
- Пополнение: записник + Скаут предлагает вечные углы строкой в брифе + развороты «тема → раскрытие».

## Как это работает в заводе (нажал → получил флагман-тему)

Прогон `python run_pipeline.py` (флагман):
1. **Актуальность данных** (`core/dedup.refresh_if_stale`) — свежая выгрузка канала для анти-повтора.
2. **Скаут** (по дню/свежести брифа; может авто-пропуститься) → бриф в `memory/briefs/` (новости = крючки/цифры).
3. **Анти-повтор** (`core/dedup.check`) — сверка с вышедшим + **домен-усталость** (2+ поста по домену за
   ~2 недели → ⚠️, не флагман) + сигнал репортажности.
4. **Роутер темы** (`core/dedup.pick_flagship_topic`) — АВТОНОМНО: годная тема-с-хребтом из брифа
   (новость = крючок) ИЛИ вечная тема из банка, если в брифе только репортаж/перегретый домен. Fail-safe:
   сбой → откат на старый hint. В логе строка **🧭 Тема флагмана — из БАНКА/брифа…**.
5. **Криейтор** пишет по закону: тема (хребет) + надевает её на настроение рынка из брифа (слой 2) +
   плотная подача §4. Контекст: `content_manual.md`, `post_standard.md`, `flagship_topics.md` (грузятся в `core/creator_bot.py`).
6. **2FA-фактчек** (`core/verify.py`, Sonnet) → Криейтор сам правит.
7. **Обложка + отложка** — GPT-обложка (если Криейтор не сделал) и постановка в «Отложенные» канала.
   (`--draft-only` останавливает ПЕРЕД этим шагом: увидеть флагман без траты GPT и без публикации.)
