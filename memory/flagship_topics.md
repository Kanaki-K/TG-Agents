# Банк вечных тем флагмана — KANAKI CRYPTO

> **Зачем.** Флагман — это своя ТЕМА (вечный хребет), а не новость дня (мануал §2, тема-гейт). Чтобы
> флагман не питался одной новостной лентой и не скатывался в новостник, темы берём ОТСЮДА. Новостной
> бриф Скаута даёт КРЮЧКИ и свежие цифры под эти темы — не сам список тем.
>
> **Кто ведёт.** Владелец — свои интересы (этот банк вырос из его записника тем). Скаут — предлагает
> вечные углы строкой в брифе («💡 вечная тема (в банк флагмана): …»). Роутер (`dedup.pick_flagship_topic`)
> — автономно берёт отсюда тему, когда в брифе только репортаж. Криейтор — читает перед письмом.
>
> **Тест на попадание в банк (= гейт флагмана):** убери новость — что останется? Останется метод /
> модель / вечная механика / урок / сравнение, полезные читателю через год → тема годится. Пять рёбер:
> своя тема · применимость · «я это прожил» · нестандартный вектор · долгий срок. Эталоны — #417/#422/#435/#416/#434.

## ⚖️ Золотое сечение (тема ↔ свежесть) — главный принцип
Не «только вечное» (застой, ощущение повтора) и не «только новости» (новостник). Баланс:
- **Хребет — вечная тема из банка.** Она несёт пользу и живёт годами.
- **Крючок — свежее.** Если под тему есть свежий повод/цифра из брифа — открой им пост (как индекс страха
  в #434). Нет повода — тема самодостаточна (математика/психология/механика), крючок не нужен.
- **Темы ВОЗВРАЩАЮТСЯ с новым углом, а не одноразовые.** «Дефицит тем» был оттого, что тему считали
  использованной после одного поста. Но портфель/DCA/смена рук заходили ПО НЕСКОЛЬКУ раз разными углами
  (#417/#422/#434 — одна жила). Повтор ловится на уровне ПРИЁМА (§4.5), а не запретом возвращаться к теме.
- **Колодец пополняется:** записник владельца (ниже) + Скаут предлагает вечные углы + Claude по запросу
  разворачивает «тема → глубокое раскрытие». Так дефицит не повторяется.
